题解：UVA10730 Antiarithmetic?

UVA10730

题意简述

给定整数 nnn，并给出 000 至 n−1n-1n−1 的一个排列 ppp（下标从 000 开始），判断这个排列是否满足：对于任意的 0≤i<j<k<n0 \le i < j < k < n0≤i<j<k<n，不存在 (pi,pj,pk)(p_i,p_j,p_k)(pi​,pj​,pk​) 构成等差数列。如果满足，则称这个序列为 “antiarithmetic” 的。

解题思路

首先，经过尝试，如果暴力枚举 i,j,ki,j,ki,j,k 并判断任意三项是否构成等差数列，结果会超时。

于是尝试枚举中间项 pjp_jpj​ 和公差 ddd，并判断 pj−dp_j-dpj​−d 和 pj+dp_j+dpj​+d 两项是否在数列 ppp 中。如果存在，则记 pj−dp_j-dpj​−d，pjp_jpj​ 和 pj+dp_j+dpj​+d 这三项的下标分别为 i,j,ki,j,ki,j,k，并判断 i,j,ki,j,ki,j,k 是否是单调的，即 i<j<ki<j<ki<j<k 或 i>j>ki>j>ki>j>k 即可。如果找到了符合条件的三项，则说明这不是 “antiarithmetic” 序列。
